# Задание на проверку качества перевода RU → EN

Дата исходной проверки — 24 ноября 2026 года.

## Цель и результат

Проверить полноту и терминологическую точность перевода на одной фиксированной записи. Сохранить доказательства и результаты в этом файле, чтобы следующие проверки могли использовать готовые материалы.

Исполнитель — Antigravity. Задание относится к проверке существующего пилота. Обнаруженные изменения программы оформлять отдельными задачами с указанием причины.

## Soniox — перевод файла в приложении

Пользователь предоставил английский текст перевода того же файла. Ниже оценивается содержание текста по прежней разметке русского оригинала. Версия модели приложения неизвестна. Озвучка Soniox, промежуточная русская расшифровка и замеры времени отсутствуют.

| ID | Цитата Soniox | Оценка по тексту |
| --- | --- | --- |
| Q01 | `pimobendan`, `cardiotonic agent` | Название препарата и группа сохранены. |
| Q02 | `dexmethylpimobendan` | Искажено название метаболита, в разметке оригинала — десметилпимобендан. Ошибка повторяется в блоке о вазодилатации. |
| Q03 | `positive nootropic effect` | Существенная подмена термина. Требуется `positive inotropic effect`, усиление сократимости. Gemini A пропустил термин, Gemini B его передал. |
| Q04 | `The myocardium and calcium are synthesized` | Возникло утверждение о синтезе. Следующая фраза верно передаёт повышение чувствительности к кальцию. Отрицание дополнительных затрат АТФ сохранено, но `oxygen energy` сливает энергию и кислород в одно понятие. В Gemini A оба понятия различимы. |
| Q05 | `vasodilating ... effect` | Смысл сохранён. Запинки не меняют названный эффект. |
| Q06 | `sildenafil ... inhibitor of phosphodiesterase 3` | Та же цифра в Gemini и двух распознаваниях оригинала. Прослушать русский фрагмент перед атрибуцией ошибки. |
| Q07 | `as do large pulmonary arteries` | Лёгочные артерии названы без лишнего элемента `large lungs` из Gemini A. Однако грамматика связывает перечисленные сосуды с «улучшением», тогда как лектор говорит об их расширении. |
| Q08 | `pre-load ... it decreases`, `post-load` | Направление изменения преднагрузки сохранено. Для постнагрузки нужен термин `afterload`. Такая же проблема в Gemini A, в Gemini B термин верный. |
| Q09 | `it works in different areas` | Финальная мысль закончена. В сохранённом тексте Gemini A окончание оборвано. |

Для очной оценки в первую очередь сопоставить русскую речь и живой английский выход на 0:33–0:57. Уточнить, слышит ли специалист сохранённый механизм действия. Задержку и результат потокового API Soniox проверять отдельным прогоном.

## Порядок выполнения

1. Прочитать этот файл и использовать существующие записи и текстовые материалы. Сначала прослушать контрольные фрагменты Q01–Q09 и заполнить таблицу результатов ниже. При отсутствии возможности слуховой проверки оставить `UNVERIFIED` и указать, какие выводы получены только распознаванием.
2. Сохранить подтверждённую русскую расшифровку с временными отметками рядом с исходной записью, например `samples/input2m.ru.reference.txt`. Отдельно отметить оговорки лектора. Этот файл станет эталоном для дальнейших сравнений.
3. При новом прогоне использовать явно указанный `samples/input2m.WAV`, подачу в реальном темпе и ограниченное ожидание последнего ответа после конца входа. Зафиксировать условие завершения и убедиться, что последняя мысль озвучена полностью.
4. Сохранять каждый прогон в отдельную папку, включая полученный текст, WAV, модель, параметры, дату, версию кода и ошибки провайдера. Сохранить SHA-256 оригинала в отчёте нового прогона, чтобы сравнивать один материал.
5. Начать с одного нового прогона Gemini после проверки существующих материалов. Дополнительные вызовы нужны при выявленном исправлении или для проверки конкретной нестабильности. Для повторной оценки использовать сохранённые артефакты.
6. Soniox проверить на том же оригинале, когда пользователь сообщит о доступности оплаченного API. До этого поставить `UNVERIFIED — нет доступного живого прогона Soniox`. Локальные тесты и Gemini Free tier позволяют продолжить текущую проверку.
7. В завершение дать краткий список подтверждённых дефектов с ID, временем RU/EN и путями к доказательствам. Сохранить результат в этом файле.
