# PharmaLive Dubber — ревью спецификации и стоимость перевода

24 ноября 2026 г. · Один вход NDI с русской речью → девять звуковых NDI-источников · Допустимая задержка до 3 секунд

**Результат первого прогона:** приёмник в локальной сети видит девять отдельных NDI-источников. На каждом звучит одна и та же русская речь в переводе на назначенный язык. Для прогона подходит любой готовый голос. Для первого этапа согласованы параллельный прогон Gemini и Soniox и ручной выбор ветки. При сопоставимом качестве и подтверждённой экономии Soniox становится основным, Gemini — резервным. На втором этапе добавляются живые субтитры для всех девяти каналов, на третьем — сменные голоса, включая ваш заранее обученный.

## 3. Альтернативная модель и измерение трёх секунд

Для сравнительного прогона предлагаю **GPT-Realtime-Translate**. Модель принимает непрерывную речь и отдаёт переведённый звук, пока докладчик продолжает говорить. Один NDI-приёмник готовит общий поток PCM16 mono 24 кГц. Девять языковых воркеров передают его в девять сессий и публикуют аудио как девять NDI-источников. Встроенного голоса достаточно. Русский поддерживается на входе, английский и немецкий — на выходе. Остальные семь целевых языков нужно сверить со списком выходных языков модели. [Realtime Translation API](https://developers.openai.com/api/docs/guides/realtime-translation) · [Поддерживаемые языки](https://developers.openai.com/cookbook/examples/voice_solutions/realtime_translation_guide)

**Измерение:** на одном контрольном компьютере одновременно записать русский NDI-вход и девять NDI-выходов с общей шкалой времени. Для короткого смыслового фрагмента взять разницу между началом этого фрагмента в русском звуке и первым слышимым словом соответствующего перевода. Размечать несколько фрагментов и в середине непрерывного доклада, чтобы увидеть накопленное отставание. Отдельно сверить, когда прозвучал перевод конца фрагмента. Время ответа API до первого байта не измеряет весь этот путь.

**Результат прогона:** по каждому из девяти языков указать p50, p95, максимум, число превышений 3 с и число пропущенных фрагментов. Если фрагмент прозвучал через 3,4 с, записать превышение. Если не прозвучал вообще — пропуск. Прослушать отрывки с отрицаниями, дозировками, единицами и названиями препаратов. Это критерии испытания. Фактических замеров в репозитории пока нет.

## 4. Субтитры и сменные голоса

**Первый прогон.** Публикацию NDI выделить в отдельный модуль. Языковой воркер передаёт ему код языка, аудиоблок, частоту и метку времени. Публикатор отвечает за звук 48 кГц и имя источника. Для прямого перевода воркер сразу передаёт звук модели. Выбор движка задаётся в настройке каждого языка.

**Этап 2. Переключаемые субтитры.** В конфигурации с основным Soniox брать текст перевода из ветки STT v6, уже испытанной на первом этапе. При отказе текстовой ветки оператор может выбрать выходную транскрипцию Gemini. Каждая переведённая реплика поступает в независимый модуль субтитров и в синтезатор с готовым голосом. Для записи формируются девять файлов `.srt`, для совместимого эфирного плеера — девять выбираемых дорожек WebVTT в HLS. При выключении или остановке синтезатора текст продолжает поступать из исходной речи. Условия приёмки приведены в [спецификации](SPEC.md#этап-2-живые-субтитры-на-девяти-языках).

**Этап 3. Сменные голоса.** Добавить выбор голосового профиля для каждого языка в уже подключённом синтезаторе. Первую замену можно проверить на `Dub_EN`, сравнив услышанную фразу с английской дорожкой субтитров.

**Ваш готовый голос.** Для голоса, обученного в ElevenLabs, в настройке языка указать его `voice_id` и совместимую потоковую модель, например Flash v2.5. Для локальных весов подключить совместимый движок синтеза через тот же интерфейс. Если имеющаяся модель принимает только аудио, потребуется преобразование голоса после синтезатора. После подключения проверить разборчивость на каждом языке и повторить тот же замер до NDI: профиль голоса и скорость синтеза могут изменить задержку. [Голосовые профили ElevenLabs](https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning/) · [Факторы задержки](https://elevenlabs.io/docs/eleven-api/guides/how-to/best-practices/latency-optimization)
